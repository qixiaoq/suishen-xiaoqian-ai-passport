# 随身小签发布准备记录

这是开发检查点，还不是已发布版本。准备公开版期间保留设备上已验证的个人版。

## 当前产物

- AI Passport 四入口固件和扫码打开的手机解读服务。
- ESP32-C3 应用镜像为 1,466,688 字节。合并镜像已验证可作为单机版从 `0x0`
  烧录；应用镜像可作为 MetaPass2 子槽候选，仍须经过其安装器和真机检查。
- 源码中 `CONFIG_XIAOQIAN_COMPANION_URL` 默认留空。未设置时设备显示配置
  提示，不生成解读二维码；设备上已经烧录的个人版仍保留原地址。
- 在 MetaPass 的 OTA 子槽中运行时，首页长按下键可选择 factory 启动器并
  重启返回；直接烧录的单机版上，此手势不执行操作。尚未在 MetaPass 真机安装。

## 提交社区前

1. 为手机解读服务选择公网 HTTPS 地址，或明确只发布自行部署版本。当前局域网
   服务无法供其他家庭的用户使用。
2. 决定其他用户如何提供 AI 密钥。不得把开发者的 API Key、可无限调用此密钥的
   公开服务或家中的局域网地址放入公开固件。公网服务需要费用和请求限制。
3. 用实际发布地址构建新固件，运行完整门禁，并在不同网络下检查四个二维码。
4. 将该固件安装到 MetaPass2 子槽，实测启动、长按下键返回、联网、黄历、
   按键、扫码和手机解读。直接烧录 MetaPass2 合并固件会替换当前单机版，
   也可能重置 Wi-Fi 信息；必须针对该次写入取得许可。
5. 公开源码可先放在自己的 GitHub 仓库，并附自行部署说明。向 AI Passport
   社区提交可安装玩法之前，仍需审查固件、截图、第三方许可和玩法介绍。

离线单机游戏属于后续独立应用。确定操作、画面和体积并完成测试后，才能装入
第二个槽位。MetaPass2 标称的槽位数是上限，不保证任意两个固件都能装下或共存。
